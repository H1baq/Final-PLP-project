# Custom Insights Feature Implementation – AI Learning Documentation

## 1. Title & Objective

**Feature:** Custom Insights – AI-style personalized wellness tips
**Technology:** Flutter (Dart) + Firebase + AI-assisted design
**Why:** To explore AI-assisted development and understand Flutter best practices while enhancing Know Your Flow.
**End Goal:** Implement a feature that generates supportive, educational wellness insights based on user profile data, preparing for future AI integration.

---

## 2. Quick Summary of the Technology

**Flutter:** Open-source UI toolkit by Google for building natively compiled applications across mobile, web, and desktop from a single codebase.
**Firebase:** Backend-as-a-Service, handling authentication, database (Firestore), and cloud storage.
**AI/Prompts:** Cursor/GPT used to fix warnings, improve architecture, and design AI-ready features.

**Real-World Example:** Health apps (like Clue or Know know_your_flow) offering personalized insights based on tracked cycles, symptoms, and moods.

---

## 3. System Requirements

* **OS:** Linux/Mac/Windows
* **Editor/IDE:** VS Code, Android Studio
* **Packages/Tools:**

  * Flutter 3.13+
  * Dart SDK
  * Firebase CLI
  * pub dependencies via `flutter pub get`

---

## 4. Installation & Setup Instructions

1. **Clone the repository:**

```bash
git clone <repository-url>
cd know_your_flow
```

2. **Install dependencies:**

```bash
flutter pub get
```

3. **Setup Firebase:**

* Add `google-services.json` (Android) and `GoogleService-Info.plist` (iOS)
* Ensure Firestore and Firebase Authentication are enabled

4. **Run the app:**

* **Web:** `flutter run -d chrome`
* **Android:** `flutter run -d <device-id>`
* **iOS:** `flutter run -d <device-id>`

## 5. Minimal Working Example

**What it does:**

* Reads user profile data from Firestore
* Generates personalized wellness insights using `InsightsService`
* Displays insights dynamically in the `InsightsScreen`

**Key Code Snippet (Service Layer):**

```dart
List<Insight> generateProfileInsights(InsightProfileInput input) {
  final insights = <Insight>[];
  
  insights.add(Insight(
    title: 'Your Cycle Rhythm',
    description: _buildCycleLengthInsight(...),
  ));
  
  return insights;
}
```

**Expected Output:**

* A list of personalized, educational insights rendered as cards in the app, reflecting the user’s cycle, mood, and symptoms.
